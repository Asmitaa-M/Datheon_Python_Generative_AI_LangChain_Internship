## Getting Started

Each task has its own README and requirements file.

1. Open the required task folder.
2. Create a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure the required API keys securely.
5. Follow the task-specific README instructions.

## Security

Never commit API keys, passwords, or private credentials. Use environment variables for sensitive configuration.
